# 대시보드 브리핑 복원

2026년 11월 22일부터 대시보드는 작업 목록과 통합 채팅에 공간을 사용한다. 브리핑의 글귀·시, 최근 AI 뉴스, 하트 보관함과 기존 취향 기록을 보존했다.

## 다시 표시하기

1. [대시보드 HTML](../automation/team-board/web/index.html)의 `<body data-briefing="off">`를 `<body data-briefing="on">`으로 변경한다.
2. 대시보드 창을 새로 고친다. 작업 집계 아래에 브리핑이 나타난다. 글귀·시와 최근 AI 뉴스는 각각 3개가 처음 보이고 더 보려면 해당 목록을 스크롤한다.
3. 글을 눌러 원문을 펼치고, ‘내 취향 보관함’에서 기존 하트를 확인한다. 이후 브리핑을 다시 닫으려면 같은 속성을 `off`로 바꾸고 새로 고친다.

## 구현과 데이터

- 화면과 보관함·원문 대화상자는 HTML의 `template[data-briefing-template]` 두 개에 있다. [화면 동작](../automation/team-board/web/app.js)의 `mountBriefing()`이 활성화 시점에만 화면을 구성하고 브리핑을 조회한다. [레이아웃](../automation/team-board/web/style.css)은 브리핑 표시 여부에 따라 작업 목록 높이를 조절한다.
- 브리핑 조회는 `GET /api/briefing`, 취향 조회와 하트 변경은 각각 `GET`, `POST /api/briefing/hearts`를 사용한다. 화면이 꺼져 있으면 이 화면에서 브리핑 요청과 갱신 타이머가 시작되지 않는다.
- Windows 하트 보관함과 추천 근거는 `%APPDATA%\Agent Mission Control\Personal Library\briefing-preferences.sqlite3`에 있다. 화면을 복원하면 [취향 관리 코드](../automation/team-board/preferences.py)가 기존 파일을 읽는다.
- [AI 뉴스](../automation/team-board/briefing.py)는 OpenAI와 Google 코리아의 RSS를 조회하며, [글귀·시](../automation/team-board/literature_feed.py)는 [기본 글 목록](../automation/team-board/daily_reading.py)과 함께 구성한다. 기본 칠판의 조회 캐시는 `runs/team-board/ai-briefing.json`과 `runs/team-board/literature-briefing.json`에 있다.
