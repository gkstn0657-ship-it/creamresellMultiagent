## 2. 판정 결과
- **제외 49개 상품**: 판정 전부 일치. 사유 문구는 7개 상품에서 분류명이 다름(예: 손 "색상 불일치" ↔ 자동 "참고(고위험): 판매처 미표시"). 결론(제외)은 같음.
- **후보**: 손 4행(트렌비 XL·M·L, LFmall XXL) 모두 자동에서도 후보이며 **순수익 4/4 일치**.
- 자동에만 있는 후보 3행: SSG(428886) M·L·XL → `후보(검토 필요)`. 손 작업에서는 Chrome으로 드롭다운을 열어 "M·L 옵션 없음, XL 매진"을 확인해 제외했으나, 확장 덤프에는 옵션 목록이 없어 자동은 "재고 사이즈·수량 불명(옵션을 열어 확인 필요)"로 표시. **숨기지 않고 검토 대상으로 넘긴 것이므로 설계 의도와 일치.**

재생 중 발견·수정한 판정 버그 3건:
1. 트렌비 "**중고**품절" 문구를 품절로 오판 → 신품 후보 누락 (수정 후 일치)
2. LFmall "XXL (110 around)" 과 "1개 남음"이 다른 줄이라 사이즈를 못 묶음 → 전 사이즈 후보 (앞 2줄 묶어 읽도록 수정 후 XXL만 후보)
3. 덤프 없는 항목에서 판정 스크립트 예외 → 방어 코드

## 3. 자동이 못 하는 것 (마지막 검토로 넘기는 항목)
- 옵션 드롭다운을 열어야 보이는 사이즈별 재고(SSG·롯데) — 다음 실행부터 `PROD_ACTIONS`(선택하세요/SIZE 선택/옵션 보기 클릭)로 시도. 오늘 덤프로는 미검증.
- 조건부 가격(첫 구매 혜택가 등)의 실제 결제가, 입점·위탁 판매자의 신뢰 판단, 크림 차트 3개월·전체 해석, 위험등급 점수표 적용.
- 대표자 추출은 페이지의 첫 "대표자" 문구를 집으므로 플랫폼 대표가 잡힐 수 있음(SSG 사례). 검토 항목으로 표시됨.
