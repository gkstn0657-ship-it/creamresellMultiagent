# 크림 차트 분석 기준 v2 (2026-11-06 재수립)

**전제**: 사서 1~3주 안에 크림에 되판다. 그래서 "지금 가격 수준"보다 **"지금 사면 2~3주 뒤 팔리느냐, 그때 가격이 버티느냐"** 를 본다.
**데이터**: 크림 거래 내역 창의 최근 체결 약 50건(사이즈·가격·날짜). 이것은 "최근 N일"이 아니라 "최근 N건"이라, 날짜로 창(7·30·90일)을 잘라 그 안의 건수를 먼저 센다. (크림 헤더의 "거래 N건"은 평생 누적이므로 쓰지 않는다.)

## 1. 유동성 (탈락 조건 아님 — 2026-11-06 사용자 결정: "유의"로 표시하고 판단은 사용자가 한다)
| 최근 30일 체결 | 처리 |
|---|---|
| 5건 미만 | **저유동 → "유의" 표시**, 위험점수 2. 네이버 검색·판정은 그대로 진행하고 후보면 `후보(유의: 저유동)`로 표기. 근거에 30일·90일 체결 수와 마지막 체결 며칠 전인지 적음 |
| 5~9건 | 분석하되 "시세 신뢰도 낮음" +1점 |
| 10건 이상 | 정상 분석 |

## 2. 사이즈 보정 지수
각 체결가를 "그 사이즈의 90일 중앙값"으로 나눈 비율(1.0 = 그 사이즈 평소 수준)로 바꿔 추세를 본다. XXL이 비싸게 팔렸다고 "상승"으로 보이는 착시(크림 헤더 등락률과 같은 문제)를 없앤다. 사이즈 체결 3건 미만이면 전체 중앙값 대비.

## 3. 지표
- 추세(단기): 최근 7일 중앙값 vs 8~30일 중앙값 (±5% 기준)
- 추세(중기): 30일 vs 31~90일 (±10%)
- 고점 위치: 현재(7일) ÷ 90일 일별 고점, 고점이 며칠 전인지
- 급등: 어느 날의 지수가 직전 7일 중앙값보다 15% 이상 높으면 급등일
- 변동성: 30일 일별 지수의 변동계수(CV)
- 거래 빈도: 최근 7일 건수 ÷ 8~30일의 7일 환산 건수

## 4. 분류와 소싱 판단 (위 순서대로 먼저 맞는 것)
| 분류 | 조건 | 판단 | 위험점수 |
|---|---|---|---|
| 급등 직후 | 14일 내 급등일 | 관망 | 2 |
| 하락 | 7일 vs 8~30일 ≤ −5% | 제외 | 2 |
| 급등 후 조정 | 45일 내 급등, 현재가 고점의 90% 미만 | 관망(바닥 미확인) | 2 |
| 상승 지속 | ≥ +5% 이고 고점권 아님 | 매수 가능 | 0 |
| 상승·고점권 | ≥ +5% 이고 고점의 95% 이상 | 조건부(마진 15% 이상) | 1 |
| 고점 횡보 | 횡보이고 고점의 95% 이상(30일 내 고점) | 조건부(마진 15% 이상) | 1 |
| 횡보 | 나머지 | 매수 가능 | 0 |
| 저유동 / 데이터 부족 | 1번 게이트 | 제외 / 보류 | 2 |

가산: 변동계수 8% 이상 +1, 최근 7일 거래 빈도가 이전의 절반 미만 +1, 중기 하락(−10% 이하) +1. 최대 3점. 이 점수는 위험 점수표의 "크림 추세" 항목으로 들어간다.

## 5. 파이프라인에서의 위치
크림 덤프 직후(네이버 검색 전)에 돌려 저유동·하락·데이터 부족은 네이버 검색을 생략한다(오늘 데이터 기준 51개 중 46개 생략 → 네이버 페이지 약 80% 절약). 최종 판정에서는 관망/조건부 규칙을 적용한다.

## 6. 오늘 데이터로 본 결과
51개 중 저유동 42, 데이터 부족 4, 급등 직후 2, 고점 횡보 1, 횡보 2. 기존 기준의 후보 4개(트렌비 3, LFmall 1)는 모두 최근 30일 체결 0~2건이라 **저유동으로 탈락** — 기존 기준이 놓친 핵심 리스크.

## 7. 아직 검증 안 된 것
- 이 기준이 실제로 "2~3주 뒤 가격"을 맞히는지는 백테스트가 없다. 체결 데이터를 90일 이상 축적하면(확장이 거래 내역 창을 더 스크롤하도록 수정) 과거 시점별 분류 → 이후 가격 변화로 검증할 수 있다.
- 임계값(5%, 15%, 95%, 8%)은 경험적 초기값이다. 보유 기간·목표 마진을 사용자에게서 받으면 조정해야 한다.

## 8. 탈락 2종류: 명백한 제외 vs 사람 검토 (2026-11-06 사용자 결정)
탈락을 한 덩어리로 버리지 않고 둘로 나눈다.
| 구분 | 분류 | 처리 |
|---|---|---|
| ~~제외~~ → 특별표시 (2026-11-07 변경) | 하락 | 제외하지 않음. 네이버 대조까지 진행하고 엑셀 `특별표시` 열에 "⚠하락추세", 차트 근거 맨 앞에 하락 근거 첨부. 고점권(조건부) 수익률 15% 미만도 제외 대신 "⚠고점권" 표시 |
| 사람 검토(물음표) | 데이터 부족, 급등 직후, 급등 후 조정 | 탈락시키지 않고 엑셀 `사람 검토` 시트로 분리. 데이터 부족은 네이버 대조 생략, 급등 직후·조정은 마진까지 계산해 같이 보여줌 |
| 통과 | 그 외(저유동은 "유의" 표시) | 기존 흐름 |
- 어느 분류를 어느 쪽에 둘지는 `chart-analyze.mjs` 의 `CLEAR_EXCLUDE`, `NEEDS_REVIEW` 두 배열만 고치면 된다. 분석 결과에 `구분` 필드(제외/검토/통과)가 붙는다.
- 마진 미달, 모델번호 없음, 협업 상품 등 계산·사실로 정해지는 제외는 그대로 `제외`. 고점권 조건부(수익률 15% 미만)도 규칙으로 정해져 있어 `제외`로 둠(검토로 바꾸려면 build-final-auto 의 해당 줄 수정).
