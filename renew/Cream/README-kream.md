# 크림(KREAM) 리셀 소싱 파이프라인 — 다른 PC 설치·실행 안내 (2026-11-06 최종)

2026-11-08 추가: 6개 에이전트 실행·검증·증빙 입력은 [에이전트 실행 계약](kream-tools/AGENTS-README.md)을 따른다. `run-all.mjs`에 통합되어 있으며, 추가 AI 감사는 `--agents-llm`(GPT-6.1 Sol High) 옵션이다.

크림 체결 데이터와 네이버 가격비교(신뢰 판매처)를 대조해 수익 후보를 엑셀로 뽑는 도구입니다.
수집은 **사용자 Chrome에 설치한 확장**이 사람 속도로 하고, 분석·판정은 로컬 스크립트가 하며, 마지막 위험등급·근거만 AI가 씁니다.
2026-11-06 기준으로 상품 200개를 한 번에 돌려 엑셀까지 자동으로 만든 구성입니다.

## 3. 설치 (1회, 약 10분)
1. 이 폴더를 통째로 복사합니다.
2. `pip install openpyxl`
3. Chrome → `chrome://extensions` → 개발자 모드 켬 → "압축해제된 확장 프로그램을 로드합니다" → `naver-extension` 폴더 선택.
   확장 아이콘을 누르면 "자동 실행" 체크와 로그가 보입니다.
4. **창 가림 설정 끄기 (중요)**: Chrome 주소창에 `chrome://flags/#calculate-native-win-occlusion` → Disabled → 다시 시작.
   끄지 않으면 다른 창에 가려진 확장 창의 페이지 로딩이 멈춰, 판매처 상세 페이지 단계가 진행되지 않습니다(2026-11-06에 실제로 겪음).
5. 코드를 고친 뒤에는 `chrome://extensions` 에서 확장 카드의 ↻를 눌러야 반영됩니다.

## 4. 실행 순서 (새 실행 = 새 폴더)
PowerShell 에서 Cream 폴더로 이동한 뒤:
```powershell
$run = "kream-runs\20261107"            # 날짜 등 새 이름
New-Item -ItemType Directory -Force $run

# ① 릴레이 서버 (창 하나 계속 띄워 둠). 대시보드: http://127.0.0.1:8787/dashboard
node kream-tools\relay-server.mjs $run

# ② 상품 ID 수집 (다른 창에서). 검색어는 여러 개 가능. 확장이 검색 페이지를 덤프하면 extract.
node kream-tools\collect-ids.mjs $run jobs "스톤아일랜드" "스톤아일랜드 자켓" "스톤아일랜드 니트"
#   → 확장 아이콘 → "지금 실행" (또는 1분 대기) → dump-S1.json ... 이 생기면
node kream-tools\collect-ids.mjs $run extract 200          # 탐색 완료 ID 제외, 최대 200개 → k50-ids.json

# ③ 전체 자동 실행 (크림 → 차트 게이트 → 네이버 → 카탈로그 → 판매처 → 판정 → 엑셀)
node kream-tools\run-all.mjs $run --max-prod=8 2>&1 | Tee-Object -Append "$run\run-all.log"

# ④ (선택) 마지막 검토: Claude Code 에서 kream-tools\risk-ai-PROMPT.md 의 프롬프트 실행 → risk-ai.json
node kream-tools\build-final-auto.mjs $run
python -I kream-tools\export-xlsx.py "$run\final-all.json" "$run\kream-auto-$(Split-Path $run -Leaf).xlsx"

# ⑤ 이번 ID를 탐색 완료 목록에 합침 (다음 실행에서 제외)
node kream-tools\collect-ids.mjs $run mark
```
Claude Code 에 시킬 때는 이렇게 말하면 됩니다: "Cream 폴더에서 README 4절 순서로 `kream-runs/20261107` 실행을 돌려줘. 스톤아일랜드, 최대 200개, 끝나면 risk-ai-PROMPT.md 로 위험등급까지 채워서 엑셀 링크 줘."

## 4-1. 에러 관리 (2026-11-07)
**보통은 명령 두 개면 된다.**
```powershell
node kream-tools\start-watch.mjs $run          # 릴레이+감시자를 숨김 백그라운드로 켜고 서로 지키게 함(창·세션을 닫아도 계속 돎)
node kream-toolsun-all.mjs $run --max-prod=8  # 시작하면 실행 전 점검을 먼저 하고, 실패하면 사이트에 접속하지 않음
```
| 구성 | 하는 일 |
|---|---|
| preflight.mjs (실행 전 점검) | Node·Python·문법·단위 시험, **가짜 상품 3개로 전체 흐름 재생**, 릴레이 버전·서비스 폴더·포트, 확장 접속, STOP, 감시자 |
| watchdog.mjs (감시자) | 15초마다 릴레이·확장·덤프 정체·STOP·빈 덤프·로그 에러·품질경보·실행 중단 확인. 중요한 문제는 **Windows 알림** |
| 자동 복구(--fix) | 릴레이가 꺼짐·예전 버전·다른 폴더 서비스 → 다시 띄움. run-all 이 **외부 원인**(덤프 정체·연결 끊김)으로 죽음 → 같은 명령으로 이어서 실행(최대 3번). 코드 에러·STOP·품질경보는 알림만 |
| 서로 지키기 | 감시자가 죽으면 릴레이가(생존 신호 90초 없음), 릴레이가 죽으면 감시자가 다시 띄움. 감시자는 동시에 하나만(kream-runs/watchdog.lock) |
| quality.mjs (품질 점검) | 검색 카드 0개 비율(50% 이상이면 run-all 중단), 카탈로그 행 0개, 재고·판매자 못 읽은 비율, 수익률 100% 초과 후보 |
| stage.json | run-all 의 현재 단계·상태·에러·이어서 실행할 명령. 다시 실행하면 이미 받은 덤프는 건너뛰고 이어감 |
| kream-error-manager | Claude Code 진단 에이전트(renew/.claude/agents/kream-error-manager.md). "kream-error-manager로 진단해줘" |

- 상태 확인: `node kream-tools\start-watch.mjs $run --status`, 기록: `$run\watchdog.log`, 품질: `node kream-tools\quality.mjs $run`
- 끄기: `node kream-tools\start-watch.mjs $run --stop` (릴레이까지: `--stop --all`)
- 사람이 결정할 것: STOP 해제(/resume), 코드 에러 수정, 품질경보 확인. 자동으로 하지 않는다.

## 6. 판정 기준 요약
- 순수익 = 크림 시세 × 0.95 − 3,000 − 매입가. 후보(2026-11-07 변경): **순수익 > 0** & 모델·색상 코드 정확 일치 & 판매처 페이지에서 재고 확인 & 품절 아님. 시세 15만원 하한도 없앰.
- 판매처 페이지를 못 열었거나 재고 문구를 못 읽어도 마진이 양수면 제외하지 않고 `후보(판매처 미확인)`·`후보(재고 미확인)`으로 포함하고 `특별표시`에 "※재고·판매자 미확인"을 단다. 소형몰 추정은 "⚠판매처 미표시·소형몰 추정". 품절·마진 0 이하·색상 코드 불일치만 제외.
- 네이버 검색(2026-11-07 변경): 낮은가격순 검색 결과에서 **위쪽 3개 카드만** 확인한다(스크롤 생략으로 요청·시간 감소, 건당 약 21초 → 약 12초 예상). 해외직구 카드도 3개 안에 포함해 센다.
- 마진 계산에 **판매처 배송비** 포함: 순수익 = 크림 시세 × 0.95 − 3,000 − (매입가 + 판매처 배송비). 수익률은 순수익 ÷ (매입가 + 배송비). 배송비를 읽지 못하면 0원으로 계산하고 특별표시에 "⚠배송비 미확인".
- 엑셀: 같은 스타일(모델번호 앞부분)의 색상·사이즈는 **한 행에 합침**. `옵션` 열에 줄마다 "색상코드 / 사이즈"가 적히고, 값이 옵션마다 다른 열은 같은 줄 순서로 적힘. `최대 순수익`·`최대 수익률`은 숫자 열.
- 색상 코드: 크림 모델번호(예: 801563051-A0029)가 판매처 제목에 그대로 있어야 함. 색상 코드가 다르거나 없으면 제외. 띄어쓰기·하이픈만 다르면(예: 801563051 A0029) 포함하고 `특별표시`에 "ⓢ코드 띄어쓰기 차이". 판매처 상품 페이지 제목에 다른 색상 코드가 보이면 제외.
- 차트(chart-criteria.md): **하락** 추세는 제외하지 않고 `특별표시` "⚠하락추세" + 차트 근거 맨 앞에 하락 근거 첨부. **고점권**(조건부)에서 수익률 15% 미만이어도 제외하지 않고 "⚠고점권: 수익률 15% 미만" 표시. **사람 검토** = 데이터 부족·급등 직후·급등 후 조정(물음표). 저유동(30일 체결 5건 미만)은 탈락이 아니라 "유의" 표시.
- 재고를 못 읽었거나 크림과 판매처 색상어가 다르면 후보가 아니라 **사람 검토**.
- 엑셀 시트: 수익후보 / 사람 검토 / 전체분석 / 제외사유 / 메타. 위험등급 열은 4단계(AI)를 돌려야 채워짐.

## 8. 2026-11-06 결과와 알려진 한계

- 차트 기준의 임계값(5%, 15%, 95%)은 경험적 초기값이고 백테스트가 없음.
