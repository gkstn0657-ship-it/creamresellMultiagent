# All Tabs Activity Recorder

사용자가 명시적으로 시작한 세션 동안 Chrome의 모든 탭에서 일어난 행동을 수집하는 Manifest V3 확장 프로그램입니다.

## 기록 범위

- 탭 생성, 닫기, 활성화 및 최상위 페이지·SPA 이동
- 클릭, 입력 발생 여부, 변경, 페이지·내부 영역 스크롤, 뒤로/앞으로 이동
- 탭 ID, 창 ID, 시각, URL의 도메인·경로, 대상 요소의 유형

입력값, 검색어, URL 쿼리 문자열, 페이지 제목, 페이지 본문 텍스트는 저장하지 않습니다. 비밀번호를 비롯한 민감한 입력값이 로그에 남지 않도록 설계했습니다.

## 설치

1. Chrome에서 `chrome://extensions`를 연다.
2. 오른쪽 상단의 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택한다.
4. 이 폴더를 선택한다.
5. 툴바의 확장 프로그램 아이콘에서 **전체 탭 기록**을 연다.

## 사용

1. **모든 탭 기록 시작**을 누른다.
2. 필요한 작업을 수행한다.
3. **기록 중지**를 누른다.
4. JSON 또는 Markdown으로 내보낸다. 새로 시작한 세션도 이전 세션을 보존합니다.

## 제한

- Chrome 내부 페이지(`chrome://`), Chrome Web Store, 일부 보호된 페이지는 Chrome 정책상 기록할 수 없습니다.
- 확장 프로그램은 사용자가 시작을 누르기 전에는 행동을 수집하지 않습니다.
- Markdown 내보내기는 구조화된 원시 타임라인을 생성합니다. 행동 목적의 자연어 해석은 생성된 JSON/Markdown을 Claude Code 또는 LLM에 전달해 후처리합니다.
