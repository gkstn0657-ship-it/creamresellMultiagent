# Cream 라이브 대시보드

기존 HTTP 서버와 CSS를 재사용한다. 기존 탐색 화면은 `/`, Herdr 관제실은 `/herdr`이다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File automation/agent-team/live-dashboard/start-herdr-dashboard.ps1
```

기본 주소: http://127.0.0.1:8875/herdr

에이전트 현황은 4단계 노드 모니터(지휘·제어 → 수집 → 판단 → 검수)로 표시한다. 상태 LED, 활동 신호 애니메이션, 전체/동작 중 필터, 노드 선택 상세 패널을 제공한다. 신호 막대는 활동 표시이며 CPU·사용량·진행률 측정값이 아니다. 로그와 공개 메시지는 상세 패널 안에서 펼쳐 본다.

연속 탐색 작업도 같은 작업 선택기에 표시한다. 기존 연속 실행기는 AI 지휘자와 구분하여 '규칙 기반 · AI 아님'으로 표시하며, 실제 상품 담당·검수 스레드가 생성되어야 해당 노드가 나타난다. 연속 작업 중지는 기존 stopWork를 사용한다. 이 화면에서 연속 작업 재개는 제공하지 않는다.

실행 스크립트는 대시보드만 백그라운드로 시작한다. 기존 `start-dashboard.ps1`의 탐색 감시 프로세스 시작 동작은 호출하지 않는다. No1이나 상품 탐색을 자동으로 시작하지 않는다.

- `kream-runs` 바로 아래의 Herdr 작업(session, mission, batches가 있는 state.json)을 자동 발견한다. 합성 Herdr 검증 폴더는 목록에 넣지 않는다.
- 2초 폴링으로 지휘자와 워커 프로세스, 목표·완료 수량, 독립 검수 확인, 수집 제외, 상품별 모델·승격·판단, 최근 30개 지휘 기록을 갱신한다. 기존 작업에 모델 기록이 없으면 현재 기본값으로 추측하지 않는다.
- 에이전트 작업 현황 카드에서 지휘자·워커·상품 담당·독립 검수·조사 스레드를 구분한다. 현재 실행 도구, 담당 상품, 실제 모델, 최근 공개 메시지와 최근 8개 활동을 표시한다. 상품 담당자의 검수 응답 대기와 검수자의 원자료 읽기도 각각 표시된다. 내부 추론이나 숨겨진 사고 과정을 노출하거나 추측하지 않는다.
- 새 런타임은 턴 시작·종료와 도구 시작·완료를 저장한다. 과거 tool_call만 있는 기록은 실행 중이라고 추측하지 않는다. 프로세스가 없거나 작업이 종료되면 애니메이션을 끄고, 60초 넘게 새 활동이 없으면 '새 기록 대기'로 표시한다(장애 확정이 아님). 상세 이벤트는 수정된 런타임으로 시작한 작업부터 남는다.
- 독립 검수 수량은 런타임의 `verifiedResult`로 원자료 basis와 별도 검수 기록을 확인한다. 수집 제외는 수익 후보나 독립 검수로 세지 않는다.
- 중지·재개는 선택한 작업에 대해 기존 Herdr CLI를 호출한다. 작업량은 유지하며, 사용한 턴 한도를 소진한 경우 사용자가 총 턴 한도를 늘려야 재개된다. 완료된 작업이나 생존 프로세스가 있는 작업은 재개하지 않는다. 실행 요청 성공과 프로세스 생존 확인은 구분한다.
- 연결이 끊기면 마지막 기록을 남기고 제어 버튼을 비활성화한다. 원자료 문자열은 textContent로 표시한다. 제어 API는 loopback의 동일 origin JSON 요청만 받는다.
- 기본 데이터 루트는 `kream-runs/agent-teams`이다. 다른 루트로 만든 작업은 표시하되 제어를 비활성화한다. 서버의 `--runs-root` 옵션으로 별도 환경을 지정할 수 있다.

검증: `node --test automation/agent-team/live-dashboard/server.test.mjs automation/agent-team/live-dashboard/herdr.test.mjs`.
브라우저 검증: 서버 실행 후 `node automation/agent-team/live-dashboard/verify-herdr-ui.mjs` (기존 panel-ui Playwright와 headless Edge 사용).
실제 저장 작업 표시, 데스크톱·모바일 레이아웃, 합성 작업 중지·재개, 자동 갱신과 연결 단절을 검증한다. 브라우저 검증은 실제 소싱 작업을 재개하지 않는다. 결과와 화면 캡처는 `kream-runs/herdr-dashboard/`에 저장한다.
